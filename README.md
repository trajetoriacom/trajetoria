ajetória FC

Jogo de adivinhação de jogadores de futebol pela trajetória dos clubes.

## Como jogar

Observe os clubes exibidos, digite o nome do jogador e confirme sua resposta. Cada acerto vale 15 pontos. Dicas custam 50 pontos e pular uma rodada custa 75 pontos.

O nome do jogador, a pontuação, os acertos e a maior sequência são usados no ranking local do navegador.

## Publicação

Publique o conteúdo desta pasta como a raiz do site. O arquivo de entrada é `index.html`.

Para evitar erro 404:- GitHub Pages: selecione a branch e a pasta `/ (root)` nas configurações de Pages.
- Netlify: use esta pasta como diretório de publicação.
- Vercel: importe o projeto como site estático, sem comando de build.
- Domínio próprio: aponte o DNS para a hospedagem e mantenha `index.html`, `app.js` e `styles.css` no mesmo diretório publicado.

O arquivo `404.html` redireciona rotas desconhecidas para o jogo em hospedagens estáticas.
